Data Flow

  • Background Thread → SenderPort::reserve() → write data → SenderPort::deliver() → fans out to all connected receivers
  • Main Loop (top) → ReceiverPort::update() — promotes pending slot to active (zero-copy)
  • Main Loop (render) → ReceiverPort::getData() — read active slot, display in ImGui
  • Main Loop (bottom) → ReceiverPort::cleanup() — clears newData flag
  • SettingsRegistry::loadJson() → deserializes JSON into registered SettingsItem<T> objects → triggers DirtyTracker::dirty()
  • SettingsRegistry::saveJson() → serializes all items back to JSON file on exit
  • Log::init(level, file) → creates console sink (ANSI auto-detect) + file sink + sets level from AppConfig::logLevel
  • Log::get("name") → returns a named logger that outputs to all sinks (console, file, ImGui panel)
  • ImGuiLogSink::draw() → renders scrollable, color-coded, filterable log panel each frame
